（招标编号：S110000A001044388001）

一、招标条件

    本招标项目  北京市西城区老旧小区管线改造南片区一期工程（初步设计、施工图设计）   已由   北京市西城区发展和改革委员会   以  关于北京市西城区老旧小区管线改造南片区一期工程实施方案的批复   批准建设，招标人为  北京市西城区城市管理委员会   投资额为   5804.06   万元，建设资金来源为  政府投资和企业自筹   ，项目出资比例为   政府投资30%，企业自筹70%   。项目已具备招标条件，现进行公开招标 。

    规模：地上建筑规模：  /  ; 地下建筑规模:   主要包括小区的室外雨污水管线改造工程，以及因管线改造而实施的道路、绿地等工程。其中:（一）改造污水管线 7019 米，污水检查井 820 座，化粪池 39 座。（二）改造雨水管线 5795 米，雨水检查井 283 座。   ; 建筑面积:  0  ㎡ ;建筑高度:  无  ;长度:  12814  m。
    招标范围：  本项目的初步设计、施工图设计、概算文件编制及《市政公用工程设计文件编制深度规定》（2025 年版）规定的其它所有工作；编制报批有关基建手续设计文件（包含图纸、概算及电子文件）；提供技术交底、承担后续各施工标段招标过程中的技术部分文件编制、配合服务、竣工验收，并负责项目施工期间的设计服务。具体详见招标文件第四章设计任务书。   ;招标内容:   设计  。
