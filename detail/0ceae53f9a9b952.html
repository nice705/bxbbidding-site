昌平区第十三批老旧小区市政管线改造项目-电力工程（初步设计、施工图设计）招标公告

（招标编号：S110000A001044389002）

一、招标条件

    本招标项目  昌平区第十三批老旧小区市政管线改造项目-电力工程（初步设计、施工图设计）   已由   北京市昌平区发展和改革委员会（北京市昌平区粮食和物资储备局）   以  北京市昌平区发展和改革委员会关于提前开展昌平区第十三批老旧小区市政管线改造项目工程勘察、设计招标工作的批复   批准建设，招标人为  北京市昌平区城市管理委员会   投资额为   2853.42   万元，建设资金来源为  市固定资产投资、区固定资产投资、自筹资金   ，项目出资比例为   100%   。项目已具备招标条件，现进行公开招标 。

二、项目概况和招标范围

    本次招标项目建设地点：  北京市昌平区昌平区  
    规模：地上建筑规模：  1）西关路2号、4号: 改造内容电力内线、电力外线。电力内线改造至入户电表管线长度2908.64米；电力外线改造至派接箱管线长度350米。 2）城角西路(甲6、6号): 改造内容电力内线、电力外线。电力内线改造至入户电表管线长度2847.32米；电力外线改造至派接箱管线长度350米。 3）西环路44号院: 改造内容电力内线、电力外线。电力内线改造至入户电表管线长度10887米。电力外线改造至派接箱管线长度2200米。 4）和平街东里: 改造内容电力内线、电力外线。电力内线改造至入户电表管线长度7807.2米；电力外线改造至派接箱管线长度2000米。  ; 地下建筑规模:   /   ; 建筑面积:  0  ㎡ ;建筑高度:  无  ;长度:  29350.16  m。
    招标范围：  4个小区内电力管线进行改造等工程的初步设计、施工图设计。   ;招标内容:   设计  。
