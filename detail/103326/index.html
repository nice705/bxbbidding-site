现就以下项目进行国内竞争性谈判采购，采购资金已全部落实，欢迎符合条件的供应商参加谈判。 一、项目名称 ：自助售货机服务保障项目 二、 柜服务项目， 由服务商投入自动售货机设备 19 台（其中单门 10 台、双门 9 台）、自助咖啡机 4 台，同时提供机内商品以及整体营运服务。为工作人员、就诊病人等提供 24 小时日常所需的饮料、食品、口罩等生活保障，为急诊 住院病人提供护理垫、女性卫生品、小便器等应急服务。 2. 商品、咖啡 报价：在售卖基准价的基础上有折扣，价格折扣率不高于 95% 。 3. 场地使用管理费：（双门售货机、单门售货柜 咖啡机）在合同期内收取中标企业场地使用管理费，收取标准：双门售货机 568 元 台 月，单门售货柜 咖啡机 406 元 台 月。 4. 服务期限： 1 年 5. 中标企业数量： 通过评审确定 1 家预中标人 四、投标人资格条件 ( 一 ) 具有企 ( 事 ) 业法人资格 ( 有行业特殊情况的银行、保险、电力、电信等法人分支机构，会计师、律师等非法人组织，行业协会等社会团体法人除外 ) ； ( 二 ) 国有企业 ; 事业单位 ; 军队单位 ; 成立三年以上的非外资 ( 含港澳台 ) 独资或控股企业； ( 三 ) 具有良好的商业信誉和健全的财务会计制度； ( 四 ) 具有履行合同所必需的设施设备、专业技术能力、质量保证体系和固定的生产经营、服务场地； ( 五 ) 有依法缴纳税收和社会保障资金的良好记录； ( 六 ) 参加军队采购活动前 3 年内，在经营活动中没有受到刑事处罚或者责令停产停业、吊销许可证或者执照、较大数额罚款 (200 万元以上 ) 等重大违法记录； ( 七 ) 未被中国政府采购网（ www.ccgp.gov.cn ）列入政府采购严重违法失信行为记录名单，未在军队采购网（ www.plap.mil.cn ）军队采购暂停名单处罚范围内或军队采购失信名单禁入处罚期和处罚范围内，以及未被“信用中国”（ www.creditchina.gov.cn ）列入严重失信主体名单或国家企业信用信息公示系统（ www.gsxt.gov.cn ）列入严重违法失信名单（处罚期内）； ( 八 ) 本项目特定资质 : 具有食品经营许可证。 ( 九 ) 投标企业应当具备服务履约的能力 。 五、谈判文件申领时间、地点、方式 （一）申领时间： 2026 年 7 月 2 日 至 2026 年 7 月 8 日 ，每日上午 08 : 3 0 至 11 : 30 ，下午 14: 3 0 至 1 7 : 00 。 （二）申领地点： 北京市 （三）申领方式 ：线上申领 。 所有报价人（供应商）在项目报名前应在军队采购网（ plap.mil.cn ）供应商管理信息系统 完成注册。 报 名价 供应商采取发送电子邮件方式提交报名材料，邮件主题：项目名称 + 项目编号 + 公司名称；邮件内容：列明公司名称、法定代表人或授权代表人姓名及联系方式；邮件附件：需采用 A4 纸幅面，将报名材料加盖企业鲜章，按顺序制作成 1 个 PDF 格式文件，文件名称与主题一致，复印件扫描无效。报名材料审核通过后，采购机构联系人向供应商邮箱发送谈判文件电子版；审核未通过的，采购机构联系人以邮件形式回复审核情况，供应商可在谈判文件申领时间内重新提交材料。采购机构或代理机构邮箱： 3985486718@qq.com 六、报价开始和截止时间及地点、方式 （一）报价开始时间： 2026 年 7 月 14 日 8 时 3 0 分。 （二）报价截止时间： 2026 年 7 月 14 日 9 时 0 0 分。 （三）报价地点：北京市 （四）报价方式：由报价供应商法定代表人或授权代表现场提交报价文件，不接受邮寄等其他方式。 七、谈判时间、地点 （一）谈判时间： 2026 年 7 月 14 日 9 时 0 0 分。 （二）谈判地点：北京市 八、本采购项目相关信息在《军队采购网》（ www.plap.mil.cn ）上发布。 九、采购机构联系方式 联 系 人： 齐老师、尚老师 办公电话： 010-6686791 6 、 010-66867912 地 址：北京市 十、监督部门联系方式 项目监督人： 孙 老师 、孔老师 办公电话： 010-668 67913 、 010-66867917 地 址：北京市 采购方式: 3 | 附件1.pdf.pdf
