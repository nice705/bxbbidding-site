海淀区东升镇北部片区朱房四街棚户区改造项目二期(剩余用地)万象南路等七条配套支路道路市政工程（勘察）招标公告

（招标编号：S110000A001044385001）

一、招标条件

    本招标项目  海淀区东升镇北部片区朱房四街棚户区改造项目二期(剩余用地)万象南路等七条配套支路道路市政工程（勘察）   已由   北京市发展和改革委员会   以  关于海淀区东升镇北部片区朱房四街棚户区改造项目二期（剩余用地）项目核准的批复   批准建设，招标人为  北京清上未来置业发展有限公司   投资额为   37737   万元，建设资金来源为  自筹资金   ，项目出资比例为   100%   。项目已具备招标条件，现进行公开招标 。

二、项目概况和招标范围

    本次招标项目建设地点：  北京市海淀区东升镇  
    规模：地上建筑规模：  海淀区东升镇北部片区朱房四街棚户区改造项目二期(剩余用地)万象南路等七条配套支路道路市政工程位于海淀区东升镇北部地区，北至规划学府树北街，西至京新高速，南至北五环，东至小月河。土地储备整理用地面积约68.74公顷(准确规模以拨地钉桩成果为准)，其中建设用地面积约26.14公顷，代征道路用地面积约15.26公顷，代征绿化用地约27.34公顷。其中：万象北路西起朱房南三街，东至朱房南一街，规划为城市支路，道路红线宽20米，全长约164米；万象中路西起朱房南三街，东至朱房南二街，规划为城市支路，道路红线宽20米，全长约204米；朱房南三街南起清河路，北至万象北路，规划为城市支路，道路红线宽20米，全长约1089米；朱房南二街南起清河路，北至朱房路，规划为城市支路，道路红线宽20米，全长约847米；学府树小街西起朱房南三街，东至毛纺路，规划为城市支路，道路红线宽20一25米，全长约777米；学府树中街南起清河路，北至万象南路，规划为城市支路，道路红线宽度25米，全长约335米；万象南路西起京新高速东小街，东至朱房南三街，规划为城市支路，道路红线宽20米，全长约200米。雨水、污水、再生水、供水、供热、供电等随路同步实施  ; 地下建筑规模:  /  ; 建筑面积:  0  ㎡ ;建筑高度:  无  ;长度:  3616  m。
    招标范围：  海淀区东升镇北部片区朱房四街棚户区改造项目二期(剩余用地)万象南路等七条配套支路道路市政工程详细勘察工作及与勘察相关的技术服务工作内容   ;招标内容:   勘察
